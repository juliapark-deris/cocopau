# 코코파우 (CocoPau)

코코파우는 **내가 가진 화장품을 한눈에 확인하고, 사용기한(유통기한)을 놓치지 않게 돕는 화장품 파우치 앱**입니다.  
구매 전에 중복 구매를 줄이고, 만료 임박 제품을 빠르게 확인할 수 있도록 설계했습니다.

## 왜 만들었나요?
- 구매 직전, 보유 제품을 바로 확인하기 어려운 문제를 해결하기 위해
- 만료된 제품을 놓쳐 피부 트러블로 이어질 수 있는 상황을 줄이기 위해

## 핵심 기능 (MVP)
- 비회원 읽기 전용 모드
- 로그인 사용자 백업/복원 흐름
- 화장품 직접 등록 (필수/선택 항목 분리)
- 바코드 스캔 + 수동 입력 보조
- 내 파우치 목록/상세/수정/삭제
- D-day 배지, 만료 임박 정렬, 만료됨 목록
- 주요 지표 이벤트 수집 (MAU, 사용자당 제품 수 등)

## 기술 스택
- **데이터 저장소:** Azure Cosmos DB for NoSQL
- **API 계층:** Azure Functions
- **버전 관리:** GitHub

## 저장소 구조
```text
.
├─ backend-functions/   # Azure Functions 코드
├─ assets/              # 정적 리소스
├─ index.html           # 웹 진입 파일(프로토타입/미리보기)
├─ app-config.js        # 앱 설정 파일
└─ prd.md               # 제품 요구사항 문서(PRD)
```

## 문서
- `prd.md`: 제품 요구사항, 범위, 성공 지표
- `AGENTS.md`: 개발 원칙, 협업 규칙, 기술 선택 기준

## 현재 범위 (이번 단계에서 제외)
- 커머스 기능(구매 연동/결제/리뷰)
- 관리자 기능
- iOS 출시
- 푸시 알림
- 외부 바코드 상품 DB 자동 연동
